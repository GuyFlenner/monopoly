### Open HITL blockers

- 🔴 **D1 — save then load in one sitting is refused** (`409 error.game_already_exists`). Leaving a
  game in the UI does not end the server session, so re-uploading the file you just downloaded is
  refused. The fix is a product decision with three defensible answers and the audit deliberately did
  not pick one: a load **replaces** the live session with that id · a load **mints a new id** and the
  file becomes a template · the player is **asked**. Today's behaviour is pinned in both languages by
  `packages/web/e2e/persistence.spec.ts`, so choosing is a test edit plus a small change.
  Documented in `docs/A11Y_AUDIT.md` §4.

### Open advisories

- 🟡 **The event log does not survive a reload** (accepted limitation of ADR-010). The board, money,

- 🟡 **Money carries no currency symbol anywhere**, while the English card catalogue writes `$50`.

### Key decisions made this session

- **ADR-010 — the local build persists its own session.** In the published build the engine runs in
  the tab, so a session is Python objects in the Pyodide heap and a reload discards it. The transport
  now snapshots to `localStorage` after each mutation and restores on a 404. Confined to
  `src/local/`; the engine keeps its no-I/O rule, `sessions.py` stays browser-free, and the app layer
  still cannot tell which build it is in.
- **The deployed configuration needs its own coverage.** The bug survived because `e2e-pages` had one
  smoke test while `e2e/` had fifty-four, and the smoke asserted the game id reached the URL while a
  *comment* claimed that was what made a reload work. A real reload against the built artifact is now
  a test; the false comment is corrected in place rather than deleted.
- **Measure before claiming.** An early probe suggested bots were hanging under Pyodide; re-measuring
  showed easy 0.9 s and hard 1.9 s per turn, so nothing was reported. Snapshot cost was measured on
  the artifact (2 ms median, 4.2 KB) rather than estimated in the ADR.
- **MON-506 was unblocked by re-reading its own reasoning.** "Invented game data" applies to the
  Israeli board's city names, which are external facts only a photograph recovers; the card texts are
  this project's own English prose, so translating them is a catalogue job — gated by a test that
  checks every figure in the Hebrew against `decks.py`'s effect table.
