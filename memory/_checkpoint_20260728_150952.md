### Open HITL blockers

- 🔴 **The Hebrew translation decision (blocks MON-501's content half).** ~250 English-only
  keys sit behind eight named exemption sets in `tests/test_locale_parity.py`. Hebrew
  conjugates verbs to the subject's gender, so a machine pass produces sentences that are
  wrong to every Hebrew speaker (`רותי עבר`). Three options were put to the owner:
  (1) model drafts, owner corrects; (2) **recommended** — owner supplies the ~40 narration
  sentences needing gender, model does the mechanical rest; (3) gender-neutral phrasing
  everywhere. **Not yet chosen.** Option 3 is a safe placeholder but must be chosen, not
  defaulted into. `grammatical_gender` already exists on `PlayerState`/`SeatConfig` and
  reaches the wire, ready for i18next context.
- 🔴 **MON-506 — Hebrew card catalogue.** 31 card texts need a native speaker. English ships;
  `cards` is registered for both languages against the English resource on purpose, with a
  tripwire asserting `cards.he.json` is still absent.

### Key decisions made this session

- **Phase 0 paid for itself repeatedly.** Six adversarial explorations before any code found
  ~20 blockers, producing ADR-007 (interrupts are a stack of frames, not a scalar phase) and
  ADR-008 (`GameView` is a projection, not the raw state). Both were load-bearing: without
  007 the specced rules were unimplementable; before 008 no endpoint returned board tiles at
  all while the RNG seed *was* on the wire.
- **Owner decisions (GAP §7), all binding**: shortage auction skipped in v1; official dual
  mortgage fee; flat tax; **no niqqud**; per-seat pronoun choice ships; Kids Mode keeps
  trading with a setup toggle. Project keeps the name **Kesef Street** (trademark discipline —
  the repo is public).
- **MON-503 closed by owner photographs**, blocked since M0. Two results: ADR-003 §4's
  slot-for-slot economic identity between the two boards is now *verified* rather than
  assumed, and the earlier web research was wrong on one street (`t34` is רח' מוריה) — the
  exact failure the no-fabrication rule exists to prevent.
- **Value-comparison tests cannot catch a re-implemented rule.** The M3 review mutated a
  projected field into the arithmetic it claims to avoid and all 111 server tests stayed
  green; all 11 promoted fields had the same hole. Every one now has a sentinel-stub
  falsifier, and M4's components copied the pattern.
- **Parallel worktree fan-out with disjoint file ownership works**, and merge conflicts were
  informative rather than costly — twice, two agents independently invented the same
  mechanism (a mortgage-fee helper; a Hebrew-exemption set), which is how the duplication got
  collapsed instead of shipped.
